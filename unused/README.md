# unused

Assets that nothing in the page references any more. Kept (instead of deleted) so
they are easy to bring back; nothing here is loaded at runtime.

- `icons/` — calendar and chevron SVGs from before the calendar used inline SVG.
- `sf/sf-ui-display-{light,bold,heavy}.woff` — font weights that `style.css` does not
  declare. Only `medium` and `semibold` are used.
- `Inter.ttf` — the 874 KB TrueType build of Inter, replaced by the 21 KB
  `Inter.woff2` subset. Safe to delete: git history keeps it.
